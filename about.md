# Auto Trajectory v0.5.2

A Geometry Dash 2.2081 / Geode v5.11.2 mod with predictive trajectory and
experimental auto-play controls. This version synchronizes tap timing with
live frame boundaries, adds bounded variable-duration robot holds, and
recognizes orb instances even when their displayed object type is Decoration.

Offline tests use a simplified physics harness. They do not replace an Android
Geode SDK build or in-game verification.
